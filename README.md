One original line of fortune-cookie wisdom for a software developer, written by a tiny deterministic program for make.fun's "Fortune Cookie Wisdom for Developers" bounty:

> A comment you wrote at 2 a.m. will one day be the only map a stranger has to your mind.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (87 characters, UTF-8, one line).
